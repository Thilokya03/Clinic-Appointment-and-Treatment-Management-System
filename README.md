# 🏥 Clinic Appointment and Treatment Management System

A comprehensive web-based clinic management system designed to streamline healthcare operations, manage appointments, track treatments, and enhance patient care. Built with modern technologies and designed for scalability.

## ✨ Features

### 👨‍⚕️ For Healthcare Providers
- **Appointment Management**: Schedule, reschedule, and manage patient appointments
- **Patient Records**: Comprehensive patient history and medical records
- **Treatment Tracking**: Monitor ongoing treatments and patient progress
- **Doctor Scheduling**: Flexible schedule management for healthcare providers
- **Staff Management**: Manage medical and non-medical staff
- **Branch Management**: Multi-branch clinic support

### 👤 For Patients
- **Online Appointment Booking**: Easy-to-use appointment scheduling system
- **Treatment History**: Access to complete treatment records
- **Payment Management**: View and manage payment history
- **Insurance Claims**: Submit and track insurance claims
- **Balance Tracking**: Monitor outstanding balances and payments

### 📊 For Administrators
- **Dashboard Analytics**: Real-time insights and statistics
- **User Management**: Manage doctors, staff, and branch managers
- **Reports Generation**: Comprehensive reporting system
- **Payment Processing**: Handle payments and insurance claims
- **Multi-branch Support**: Manage multiple clinic locations

## 🛠️ Tech Stack

### Frontend
- **React** 18.x - UI library
- **Vite** - Build tool and dev server
- **React Router DOM** - Navigation and routing
- **Material-UI (MUI)** - Component library
- **React Icons** - Icon library
- **CSS3** - Styling with theme support (Light/Dark mode)

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web application framework
- **MySQL** - Database
- **JWT** - Authentication
- **Middleware** - Custom authentication and authorization

## 📦 Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v18.0.0 or higher)
- **npm** or **yarn**
- **MySQL** (v8.0 or higher)
- **Git**

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/clinic-management-system.git
cd clinic-management-system

### 2. Backend Setup

```bash
cd backend
npm install

### 3. Frontend Setup

```bash
cd frontend
npm install

## Running the Backend

1. Make sure you are in the `Backend` directory:
   ```bash
   cd Backend
   ```

2. Start the development server:
   ```bash
   npm start
   ```

   This will start the frontend application, and it should be accessible at `http://localhost:3000` by default.

## Running the Frontend

1. Make sure you are in the `Frontend` directory:
   ```bash
   cd Frontend
   ```

2. Start the backend server:
   ```bash
   npm start
   ```
