# Reports & Analytics Module

## Overview
Comprehensive reporting system for Super Admin with 5 key business intelligence reports.

---

## 📊 Reports Available

### 1. Branch-wise Appointment Summary
**Purpose:** Track daily appointment statistics per branch  
**Access:** Admin Dashboard → Reports → Branch Appointments Tab

**Features:**
- Daily appointment breakdown by branch
- Status categories: Scheduled, Completed, Cancelled
- Color-coded summary cards showing totals
- Date selector to view specific days
- Real-time data refresh

**Metrics Displayed:**
- Branch ID and Name
- Scheduled appointments count
- Completed appointments count  
- Cancelled appointments count
- Total appointments per branch

**Use Cases:**
- Monitor daily clinic activity across branches
- Identify busy vs slow branches
- Track appointment completion rates
- Analyze cancellation patterns

---

### 2. Doctor-wise Revenue Report
**Purpose:** Track revenue generated by each doctor  
**Access:** Admin Dashboard → Reports → Doctor Revenue Tab

**Features:**
- Complete list of all doctors with revenue
- Sorted by highest revenue first
- Percentage contribution calculation
- Total revenue summary card
- Visual revenue indicators

**Metrics Displayed:**
- Doctor ID and Name
- Total Revenue (LKR)
- Percentage of total clinic revenue
- Revenue trends

**Use Cases:**
- Performance evaluation of doctors
- Revenue distribution analysis
- Commission/incentive calculations
- Resource allocation decisions

---

### 3. Outstanding Balances Report
**Purpose:** Track patients with unpaid bills  
**Access:** Admin Dashboard → Reports → Outstanding Balances Tab

**Features:**
- List of all patients with due payments
- Detailed payment breakdown
- Total outstanding amount summary
- Patient contact information
- Sortable by amount due

**Metrics Displayed:**
- Patient ID and Name
- Total bill amount
- Amount paid by patient
- Amount paid by insurance
- Outstanding balance (Due Payment)

**Use Cases:**
- Accounts receivable management
- Follow-up prioritization
- Cash flow monitoring
- Payment collection planning

---

### 4. Treatment Statistics by Category
**Purpose:** Analyze treatment popularity over time  
**Access:** Admin Dashboard → Reports → Treatment Statistics Tab

**Features:**
- Custom date range selection
- Treatment count by category
- Percentage distribution
- Total treatments summary card
- Period comparison capability

**Metrics Displayed:**
- Treatment name/category
- Number of treatments performed
- Percentage of total treatments
- Period: Start date to End date

**Use Cases:**
- Inventory planning (medical supplies)
- Staff training needs identification
- Service offering optimization

### 5. Insurance Coverage vs Out-of-Pocket

**Features:**

## 🛠️ Technical Implementation

### Frontend
**File:** `frontend/src/pages/Reports/Reports.jsx`

**Technology Stack:**
- React 18 with Hooks
- Material-UI v5 (Tables, Tabs, Cards, Charts)
- Axios for API calls
- JWT authentication

**Component Structure:**
```
Reports Component
├── Tab Navigation (5 tabs)
├── TabPanel 1: Branch Appointments
│   ├── Date Selector
│   ├── Summary Cards (3)
│   └── Data Table
├── TabPanel 2: Doctor Revenue
│   ├── Total Revenue Card
│   └── Data Table with percentages
├── TabPanel 3: Outstanding Balances
│   ├── Total Outstanding Card
│   └── Data Table with payment breakdown
├── TabPanel 4: Treatment Statistics
│   ├── Date Range Selector
│   ├── Total Treatments Card
│   └── Data Table with percentages
└── TabPanel 5: Insurance Comparison
    ├── Summary Cards (3)
    └── Data Table with coverage %
```

### Backend
**File:** `backend/Routes/reportsRoutes.js`

**API Endpoints:**

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/api/reports/branch-appointments?date=YYYY-MM-DD` | GET | Admin | Branch appointment summary |
| `/api/reports/doctor-revenue` | GET | Admin | Doctor revenue report |
| `/api/reports/outstanding-balances` | GET | Admin | Patients with due payments |
| `/api/reports/treatment-stats?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD` | GET | Admin | Treatment statistics |
| `/api/reports/insurance-comparison` | GET | Admin | Insurance vs patient payments |
| `/api/reports/summary` | GET | Admin | Overall clinic summary (bonus) |

**Database Queries:**

1. **Branch Appointments:**
   - Joins: `branch` → `staff` → `doctor_schedule` → `appointment`
   - Groups by: `branch_id`, `branch_name`
   - Aggregates: COUNT by status

2. **Doctor Revenue:**
   - Joins: `staff` → `doctor` → `doctor_schedule` → `appointment` → `payment`
   - Groups by: `doctor_id`, `doctor_name`
   - Aggregates: SUM of patient_paid + insurance_paid

3. **Outstanding Balances:**
   - Joins: `patient` → `payment`
   - Filter: WHERE `Due_payment` > 0
   - Groups by: `patient_id`
   - Aggregates: SUM of payment amounts

4. **Treatment Stats:**
   - Joins: `treatment_catalog` → `treatment` → `appointment`
   - Filter: WHERE appointment_date BETWEEN start_date AND end_date
   - Groups by: `treatment_name`
   - Aggregates: COUNT of treatments

5. **Insurance Comparison:**
   - Joins: `insurance` → `insurance_claim` → `payment`
   - UNION with no-insurance payments
   - Groups by: `insurance_name`
   - Aggregates: SUM of insurance and patient payments

## 🚀 How to Use

### For Super Admin:

1. **Access Reports:**
   - Login as Admin
   - Navigate to Dashboard
   - Click "Reports" in sidebar OR
   - Go to `/dashboard/reports`

2. **View Branch Appointments:**
   - Select tab "Branch Appointments"
   - Choose date from date picker
   - Click "Refresh" to update data
   - View summary cards and detailed table

3. **Analyze Doctor Revenue:**
   - Select tab "Doctor Revenue"
   - View total revenue card
   - Check individual doctor contributions
   - Compare percentages

4. **Track Outstanding Balances:**
   - Select tab "Outstanding Balances"
   - View total outstanding amount
   - See patient-wise breakdown
   - Prioritize collection efforts

5. **Review Treatment Stats:**
   - Select tab "Treatment Statistics"
   - Choose start date and end date
   - Click "Generate" to create report
   - Analyze treatment popularity

6. **Compare Insurance Coverage:**
   - Select tab "Insurance Analysis"
   - View summary cards
   - Compare insurance providers
   - Analyze coverage effectiveness

## 🔒 Security & Access Control

### Authentication:
- JWT token required for all endpoints
- Token stored in localStorage as `catms_token`
- Auto-included in Axios headers

### Authorization:
- **Admin Only:** All reports endpoints
- Role check via `staffAuth(['Admin'])` middleware
- Unauthorized access returns 403 Forbidden

### Data Privacy:
- No patient sensitive data exposed unnecessarily
- Aggregated data for privacy
- HIPAA-compliant data handling

## 🐛 Troubleshooting

### "No data available" in reports:
1. Check if appointments exist in database
2. Verify selected date has appointments
3. Ensure payments are recorded
4. Check doctor schedules are created

### "Error fetching report":
1. Verify backend is running (port 3000)
2. Check JWT token is valid
3. Confirm user role is 'admin'
4. Check browser console for specific errors
5. Verify database connection

### Empty revenue report:
1. Ensure payments are linked to appointments
2. Check doctor_schedule has appointments
3. Verify payment amounts are not null

### Date range errors (Treatment Stats):
1. Ensure start_date < end_date
2. Check date format: YYYY-MM-DD
3. Verify appointments exist in date range
